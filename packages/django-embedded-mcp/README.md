# django-embedded-mcp

Reusable, product-neutral primitives for an OAuth-protected MCP server embedded in
Django. Version 0.3.0 owns canonical resource comparison, Bearer challenges,
public-client callback policy, CIMD validation/fetching, DCR parsing, token digests,
refresh-family decisions, CORS/auth middleware, and MCP SDK configuration.

The host product owns branding, URLs, ORM state, Agent Contract projection, tool
dispatch, capabilities, ownership, approvals, audit persistence and release evidence.
